**What I'm working on**

Agents write code faster than anyone can review it, and "the tests passed" stopped
being evidence. Most of my open-source time goes to the referee for that problem:
making a claim re-provable instead of taking an agent's word for it.

---

**Selected work**

**[receipts](https://github.com/shaheershoaib/receipts)** · JavaScript
A verification layer for AI-written code. Defines the Gates — the standard a fix
must clear — and enforces them in CI. An agent can type "Fixed ✅"; it can't fake
the reported symptom still being there when `receipts` re-runs it.

**[system-explainer](https://github.com/shaheershoaib/system-explainer)** · TypeScript
Generates an interactive onboarding course from a repo, then proves the course is
true — every snippet grounded against source, every claim adversarially checked,
the teaching measured with a simulated learner.

**[fanout](https://github.com/shaheershoaib/fanout)** · Python
Works out which coding tasks can run in parallel, which have to serialize, and in
what order. Standard library only, no dependencies.

Smaller tools: **[design-audit](https://github.com/shaheershoaib/design-audit)**
(extracts the design system a codebase already has) and
**[setup-audit](https://github.com/shaheershoaib/setup-audit)** (catches agent
config that silently stopped working).
