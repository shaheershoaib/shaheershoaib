I build **agent skills** — small, dependency-free tools that make AI coding agents accountable for what they claim.

Agents write code faster than anyone can review it, and "the tests passed" stopped being evidence. Most of what I ship is the referee for that problem: making a claim re-provable instead of taking an agent's word for it.
